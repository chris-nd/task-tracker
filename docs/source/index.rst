Documentation Task Tracker CLI 
==============================

Task Tracker CLI est une application en ligne de commande permettant de créer,
modifier, filtrer et suivre des tâches au fil du temps.

Le projet a été conçu pour rester simple, portable et facilement exploitable
depuis un terminal. Les tâches sont stockées localement dans un fichier JSON et
chaque élément dispose d'un identifiant, d'une description, d'un statut et de
métadonnées de suivi.

Le guide suivant présente les étapes d'installation, les commandes disponibles,
la structure du projet et les références techniques générées automatiquement.
